# senior-project-practice

A simple Python program that displays your Senior Project Developer Profile.

## Usage

Run the program with:
```bash
python3 app.py
```

## Setup

Edit the variables in `app.py` with your information:
- Name
- Major
- Technology Interest
- Skill Goal
